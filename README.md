# Crazy Water World: Splash of Hearts Carnival

A one-day water festival website for **Crazy Water World**, Bukit Jalil, Kuala Lumpur, on **17 July 2027, 10:00–20:00**.

Theme: 水花连众心，多元共享乐 (Splash Connects Hearts, Diversity Shares Joy).

## How to run
Open `index.html` directly in any modern browser. No build step or server is required.

## Main features
- Responsive Persona-inspired layout with waves, bubbles and splash motifs
- Countdown to 17 July 2027, 10:00
- Filterable festival agenda with 12 timed activities
- Activity detail modal with safety notes
- Simulated RSVP form with live validation
- Mobile hamburger menu
- Mobile agenda displayed as stacked cards

## AI tools used
- Website design: Claude Sonnet 5.5 (selected starting design), compared with DeepSeek 4.1 Flash and Gemini 3 Model
- Modifications: AI coding assistant + manual review and testing
